AgentPod · Windows

Windows 설치 가이드

WSL 없이 네이티브 Windows에서 AgentPod를 설치하고 첫 실행까지 하는 방법. Docker Desktop과 Python만 있으면 됩니다.

Windows 10/11 Docker Desktop Python 3.10+ WSL 불필요
준비물 ① 설치 ② 첫 실행 동작 확인 문제 해결 명령어 요약

0준비물

체크리스트
  • Windows 10 22H2+ 또는 Windows 11
  • Docker Desktop 설치 & 실행 중
  • Python 3.10+ 설치 (설치 시 "Add python.exe to PATH" 체크)

WSL2를 이미 쓰고 있다면 WSL2 가이드를 따라도 됩니다 — 이 가이드는 WSL 없이 Windows에서 바로 실행하는 경로입니다.

1설치

  1. 소스 가져오기

    PS> git clone <repo-url>
PS> cd kaon_agentpod

  2. 설치 스크립트 실행

    install_windows.bat을 탐색기에서 더블클릭하거나, 터미널에서:

    PS> .\install_windows.bat
# 이미지 빌드를 나중에 하려면:
PS> .\install_windows.bat --no-build

    Docker·Python 확인 → 전용 venv(%USERPROFILE%\.venvs\agentpod)에 agentpod 설치 → 사용자 PATH 등록 → 이미지 빌드까지 자동으로 합니다.

  3. 설치 확인

    PS> agentpod --help

    설치 스크립트를 돌린 그 창에서 바로 잡힙니다. 새로 여는 터미널 창도 자동으로 PATH가 적용됩니다.

알려진 이슈: pip install --upgrade pip을 pip.exe로 직접 실행하면 Windows에서 "자기 자신을 수정할 수 없다"는 오류가 납니다(pip.exe가 실행 중인 자기 파일을 못 바꿈). install_windows.ps1은 이 문제를 피하려고 python -m pip 형태로 실행합니다 — 수동 설치 시에도 이 방식을 쓰세요.

2첫 실행

  1. 프로젝트로 이동

    PS> cd C:\path\to\your\project

  2. 인증 준비 (택1)

    API 키: 프로젝트 루트에 .env 생성

    # .env
ANTHROPIC_API_KEY=sk-ant-...

    또는 대화형 로그인:

    PS> agentpod shell
agent@…$ claude login
agent@…$ exit

  3. 실행

    PS> agentpod run
# 격리된 컨테이너 안에서 Claude Code 대화형 세션 진입

    여러 프로젝트를 폴더로 오갈 필요 없이 메뉴로 고르고 싶다면 메뉴 가이드 참고.

3동작 확인 (스모크 테스트)

PS> agentpod run
# 다른 창에서:
PS> agentpod status                 # agent-… 컨테이너가 running 인지
PS> $C = (docker ps --filter name=agent- --format "{{.Names}}" | Select-Object -First 1)
PS> docker exec $C bash -lc "whoami; id -u; claude --version"
# agent / 1000 / 버전 문자열
확인 항목기대값
컨테이너 상태running
사용자 / uidagent / 1000
Claude Code버전 문자열 출력
마운트docker inspect $C로 C:\Users\... 경로가 /home/agent/.claude 등에 매핑됐는지

4문제 해결

증상해결
Docker not foundDocker Desktop을 설치하고 실행하세요. 트레이 아이콘이 켜져 있어야 합니다.
Docker daemon not reachableDocker Desktop 앱이 완전히 켜질 때까지(고래 아이콘 정적 상태) 기다린 뒤 재시도.
python이 안 잡힘Python 설치 시 "Add python.exe to PATH"를 체크하지 않은 경우입니다. 재설치하거나 수동으로 PATH에 추가하세요.
설치 후에도 agentpod가 안 잡힘새 터미널 창을 열어보세요(PATH는 새 프로세스부터 적용). 그래도 안 되면 %USERPROFILE%\.venvs\agentpod\Scripts가 사용자 PATH에 있는지 확인.
pip install --upgrade pip 오류정상적인 install_windows.bat 실행이라면 이미 우회되어 있습니다. 수동 설치 중이라면 python -m pip install --upgrade pip로 실행하세요.
한글이 깨져 보임(콘솔)chcp 65001로 콘솔 코드페이지를 UTF-8로 전환한 뒤 실행하세요. .bat 스크립트들은 이미 자동으로 처리합니다.
마운트된 프로젝트 파일 쓰기 오류Docker Desktop의 파일 공유 설정(Settings → Resources → File sharing)에서 해당 드라이브가 공유돼 있는지 확인.

5명령어 요약

PS> agentpod build [--force]   # 이미지 빌드
PS> agentpod run              # 컨테이너 스폰/재사용 → Claude 대화형
PS> agentpod shell            # 컨테이너 bash (로그인·디버깅)
PS> agentpod status           # 전체 컨테이너·세션 수
PS> agentpod stop             # 현재 프로젝트 컨테이너 stop
PS> agentpod rm               # stop + 제거
PS> agentpod export           # 설치한 플러그인/MCP를 팀원과 공유용으로 저장

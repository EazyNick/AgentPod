메뉴 가이드 — agentpod

cmd나 PowerShell에서 agentpod라고만 치면, agents\ 아래 폴더 중 하나를 번호로 골라 바로 실행·접속·공유까지 하는 방법. 별도 파일을 더블클릭할 필요가 없습니다.

agentpod 한 마디 폴더 번호 선택 run / shell / export
개요 ① 사용법 ② 선택 후 동작 ③ 목록에 없는 폴더 문제 해결

0개요

이 저장소는 agents\jira, agents\n8n, agents\verify처럼 폴더 하나가 에이전트 하나에 대응하는 구조입니다. 매번 cd로 폴더를 옮기고 agentpod run을 치는 대신, 저장소 루트에서 agentpod라고만 치면 번호로 골라서 바로 실행할 수 있습니다.

1사용법

  1. 저장소 루트에서 agentpod 실행

    cmd나 PowerShell에서 저장소 루트(agents\ 폴더가 있는 곳)로 이동한 뒤:

    PS> agentpod

    인자 없이 agentpod만 치면 서브커맨드 대신 이 메뉴가 뜹니다. agentpod run처럼 명령어를 직접 쓰고 싶으면 그대로 써도 됩니다 — 메뉴는 아무 인자도 없을 때만 나타납니다.

  2. 번호 선택

    === AgentPod ===

  1) jira
  2) n8n
  3) verify

  P) 다른 경로 직접 입력
  Q) 종료

실행할 에이전트 번호: 1

    목록은 agents\ 바로 아래 폴더들을 자동으로 스캔한 것입니다 — 새 폴더를 추가하면 다음 실행 때 바로 목록에 나타납니다.

  3. 동작 선택

      선택: C:\...\agents\jira
  R) 실행 (agentpod run)
  S) 셸 접속 (agentpod shell)
  E) 공유용으로 내보내기 (agentpod export)
  B) 뒤로

동작 선택: R

2선택 후 동작

키실행되는 것용도
Ragentpod run그 폴더의 컨테이너를 스폰/재사용하고 Claude Code 대화형 세션으로 들어갑니다.
Sagentpod shell컨테이너 안 bash로 접속 — 최초 claude login이나 디버깅용.
Eagentpod export그 폴더에서 설치한 플러그인/스킬·MCP 서버를 agent.toml/.mcp.json으로 기록해 팀원과 공유할 준비를 합니다. 자세한 내용은 공유 가이드 참고.
B—폴더 목록으로 되돌아갑니다.

R/S로 세션에 들어간 뒤 Ctrl+D 등으로 빠져나오면 메뉴로 돌아옵니다. E는 끝나면 결과를 보여주고 Enter를 누르면 다시 동작 선택으로 돌아갑니다.

3agents\에 없는 폴더를 실행하고 싶다면

메인 화면에서 P를 선택하면 경로를 직접 입력할 수 있습니다 — agents\ 밖에 있는 프로젝트도 이 메뉴로 다룰 수 있습니다.

실행할 에이전트 번호: P
프로젝트 경로 입력: C:\work\my-other-project

4문제 해결

증상해결
목록에 폴더가 하나도 안 뜸agents\ 폴더가 있는 저장소 루트에서 실행 중인지 확인하세요(cd로 이동). 없거나 비어있으면 P로 경로를 직접 입력하세요.
한글이 깨져 보임cmd/PowerShell 창의 코드페이지가 UTF-8이 아닌 경우입니다. chcp 65001을 먼저 실행한 뒤 agentpod를 다시 치세요.
agentpod을 찾을 수 없다는 오류설치 가이드대로 install.bat을 먼저 실행하세요.
실행(R) 중 오류가 남같은 오류가 agentpod run을 직접 쳤을 때도 나는지 확인 — 메뉴는 껍데기일 뿐, 실제 문제는 설치 가이드 §4 문제 해결 참고.
